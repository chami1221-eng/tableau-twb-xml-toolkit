**ダッシュボードのフィルターは、同じデータソース（DS）を使うシートにしか効かない。**
表ごとに CSV / DS を分けると、同じ「年」フィルターが表の数だけ並んだり、一部のグラフにだけ効かなかったりする。

**共通の軸（年・地域・性別など）を持つ表は、縦積み（UNION）で1つの CSV にまとめる。**
1列目に `表`（どの表の行か）を持たせ、各シートは `表='xxx'` で自分の行だけを使う。JOIN ではなく UNION（JOIN すると行が複製されて集計が静かに壊れる）。

**代償（必ず守る）:**
- **全シートに `表` の固定フィルターが要る。** 1枚でも漏れると別の表の行まで集計に入り、**publish もエラーも出ずに数字が大きくなるだけ**。生成時に「各シートに `[表]` フィルターがちょうど1本」を機械チェックする
- 縦積みで他の表の行が空になる列は、**日本語の埋め草（例「（地域なし）」）で埋める**。空のままだとフィルターに「Null」が出る
- ただし**埋め草がフィルターの選択肢に並ぶ**ことがある（フィルターはCSV全体の値を引く）。フィルターに出す列は、どの表の行にも実在の値を入れる
- フィルターが効くのは**そのフィルター列を宣言しているシートだけ**。効かせたいシートには `<filter>` と `<slices>` の両方を書く

**How to apply:** freetext-to-tableau の `freetext_union.csv` がこの形（表＝会話集計／ワードクラウド／会話ログ／共起ネットワーク）。
