**view 画像（`tools/tableau_rest.py view-image`）は実画面の再現ではない。** 静止画で揃っていることを根拠に「レイアウトは大丈夫」と判断しない。

静止画に出ないもの（実測）:
- チェックボックス型フィルターの先頭の「**(すべて)**」行と、**スクロールバー**
- 1行の高さ。静止画 ≒18px／Web ≒24px／Desktop（150%表示）≒28px。**表示倍率で変わる**
- 文字の大きさ。実画面の方が大きく、長いシート名（＝ダッシュボード上のタイトル）が2行に折れて本体が縮む

**Why:** 静止画だけ見て問題なしとしたダッシュボードが、実画面では絞り込みリストの末尾・凡例の最後の項目が2回続けて切れていた。高さを積み増しても、倍率が変わるといたちごっこになった。

**How to apply:**
- 絞り込みは **`mode='checkdropdown'`（複数選択ドロップダウン）** にする。1行なので倍率に左右されない。
  filter zone の属性は `h id mode name pane-specification-id param type-v2 w x y`（Tableau が書き出す形）
- チェックボックスを残すなら高さ ≧ 36 ＋ 28 ×（項目数＋1）。凡例も見出し＋1行28pxで取る
- シート名は1行に収まる長さにする
- 最後は Tableau Cloud の画面（またはDesktop）で一度見る
- 資料用の画像はシート単体の view 画像から取れる。**ダッシュボードを資料の画像に合わせて縦長に作らない**（画面で見るダッシュボードは1画面に収める）
