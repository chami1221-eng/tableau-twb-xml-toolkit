**Tableau は配置（力学レイアウト）を計算しない。座標を前処理で計算して列で持たせる。**

## データ
- 1本の線＝2行（`順序`=1 の端点 → `順序`=2 の端点）。列＝`エッジID, 順序, キーワード, 座標X, 座標Y, 座標Y2, 共起回数, 語の出現件数, ラベル語`
- 座標は Fruchterman-Reingold ＋**中心への弱い重力**（無いとグループごとに離れていく）。0〜100 に正規化
- 引力に共起回数を掛けない（強い辺だけ縮んで潰れる）。重みは丸や線の見た目にだけ使う
- 辺は上位N本に絞る（全部描くと毛玉）。**グループをまたぐ語（橋）が絡む辺は別枠で残す**（読みどころは橋）
- 孤立した小島があると正規化に引っ張られて本体が隅に固まる → 既存の語同士を結ぶ最強の辺を足して1つにつなぐ
- ダッシュボードのフィルターを効かせるなら、**共起はフィルターの軸ごとに数え直す**（座標は全体で1回だけ計算し、動かさない）
- 実装＝`.claude/skills/freetext-to-tableau/preprocess.py`（`force_layout` / `select_edges`）

## シート
- `rows=(AVG(座標Y) + AVG(座標Y2))` / `cols=AVG(座標X)` の二重軸（→ `feedback_twb_dual_axis_xml.md`）。両軸のレンジを固定
- 線レイヤ: `mark=Line` / `lod=エッジID` / `path=順序` / 色=グループ / 太さ一定
- 丸レイヤ: `mark=Circle` / **`lod=キーワード`**（エッジIDにすると1つの丸＝2語になり、押した語が決まらない）/ `size=SUM(語の出現件数)` / `text=MIN(ラベル語)`
- **ラベルを次元のまま Text に置かない**（マークが端点ごとに割れて線が消える）。`MIN()` にする。ラベルは1語1か所だけ（データ側で決めておく）
- ラベルの重なり判定（cull）は切る。ハブの語が丸ごと消える
- 軸は `<format attr='display' … value='false' />` で隠す
- 品詞フィルターは効かせない（片方の端点だけ落ちて線が点になる）

**注意:** データが増えると配置が全部変わる。月ごとに見比べるなら座標を台帳として固定し、新しい語だけ追加で置く。
