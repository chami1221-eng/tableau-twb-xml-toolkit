# table-to-tableau — 表のデータ → Tableau

```
CSV（1本＝1つの表） ──build_twbx.py──▶ .twbx ──▶ Desktop で開く / tools/publish.py で Cloud へ
```

## ★ 自由記述の型（freetext_union.csv）に詰め込まない

`freetext-to-tableau` の雛形は**自由記述を語に分けた結果**のための形です。
列（座標X・ネガティブ件数・語の出現件数 など）にはそれぞれ決まった意味があり、グラフはその意味で集計します。

**表のデータをその列に入れて表示名だけ変えると、意味の違う値が同じグラフで足し合わされる。**
2026-10 に実際に起きたこと（架空の例に置き換えて記載）:
- 区のランキングに、区ではない「特別支援学校」が並んだ（別の表の行が同じ列に積まれていた）
- 「既往がある児童」と「エピペンを持っている児童」を同じ列で足し、同じ児童を二重に数えた

表のデータはこのスキルで作る。**複数の表を「表」列で縦に積んで1本にしない**（このスキルは表ごとに別のデータソースにする）。

## 手順

### 1. データを確かめる（利用者に聞く）
1. ファイル（CSV か Excel。**1行＝1件**。Excel は CSV で保存し直してもらう）
2. 表が複数あるなら、**それぞれ何の1件か**（児童1人／滞納1件／陳情1件 など）。1件の単位が違う表は混ぜない
3. **個人情報（氏名・住所・電話番号など）が含まれていないか**。含まれていたら止めて判断を仰ぐ
4. 文章の列（自由記述）があり、その言葉を分析したいなら `freetext-to-tableau` へ

### 2. 1回流す
```bash
python .claude/skills/table-to-tableau/build_twbx.py data.csv -o out/表データ.twbx --title "◯◯の状況"
```
- 列の型は自動で決める（数字だけの列＝数値、それ以外＝項目）。名前が「ID・コード・番号・年度・年・月」で終わる数字の列は項目として扱う（足さない）
- 名前に「率・割合・平均・単価・％」を含む数値は**平均**で集計する（合計しない）
- 数字のカンマ（`1,234`）は外して数値にする
- 文章の列（平均40文字超）はグラフに使わず、`★文章の列あり` と出す

### 3. 出力を利用者に見せて確かめる
「数値の列」「棒グラフ」の行を見せ、**足し合わせてよい数値か**を利用者に確かめてもらう。
違っていたら指定し直す:
```bash
python .claude/skills/table-to-tableau/build_twbx.py data.csv -o out/表データ.twbx \
  --dims 区,施設種別 --measure 利用者数        # 棒にする項目（この順）と主に見る数値
python .claude/skills/table-to-tableau/build_twbx.py a.csv b.csv -o out/2表.twbx   # 表ごとに別のダッシュボード
```
`--measures` で「数値として集計する列」を明示できる。

### 4. Desktop で開いてもらう
`はじめに.md` の手順4と同じ（最終版で1回だけ。エラーが出たら 4-1）。

## 作るもの（1表あたり）

| シート | 中身 |
|---|---|
| `{項目}別 {数値}` | 横棒・大きい順（値の種類が2〜30の項目から最大3枚。`--max-charts`） |
| `{項目} × {項目}　{数値}` | クロス表（色＋数値）。棒の項目が2つ以上あるとき |
| `明細（{数値}）` | 項目を並べた表 |
| ダッシュボード | 上の全部＋絞り込み（最大4つ。**同じ表の全シートに効く**） |

## XML の出どころ（推測で書いたものは無い）
- データソース・棒・クロス表・明細・ダッシュボード・window: `freetext-to-tableau/template/freetext_dashboard.twb`（Desktop 2026.1 で表示確認済み）と同じ形
- 全シートに効く絞り込み: `<filter … filter-group='N'>` ＋ `level-members`（Tableau が保存した TWB に 96 件ある形）
- 最後に `twb-public-export` と同じ Desktop 互換変換と内容モデル検査を通す
- 足したい表現があれば、先に `twb-xml-syntax-miner` で手本を引く（`CLAUDE.md` の「必ず守ること」4）

## できないこと
- 日付は文字として扱う（`2026-04` の形なら並び順は正しい）。日付の階層（年→四半期→月）は Desktop で型を変える
- 表どうしの結合（リレーション）は作らない。結合が要るなら、先に1件の単位をそろえた1本の表にする
- 地図は作らない
